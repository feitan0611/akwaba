# Architecture Decision Records (ADR)

Un ADR consigne une décision structurante : **contexte → décision → conséquences**. On ne modifie
pas un ADR accepté ; on en écrit un nouveau qui le remplace.

| N° | Titre | Statut |
|----|-------|--------|
| [0001](0001-interfaces-et-moteur-mock.md) | Interfaces IA et moteur « mock » | Accepté |
| [0002](0002-contrat-api.md) | Ajustements du contrat d'API | Proposé — à valider |

Prochains ADR attendus : choix du modèle STT/LID, choix du modèle de traduction, choix du LLM,
choix du modèle TTS (à l'issue du benchmark du sprint S1).

Modèle : copier un ADR existant et renseigner Statut, Date, Contexte, Décision, Conséquences.

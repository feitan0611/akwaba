# Architecture Decision Records (ADR)

Un ADR consigne une décision structurante : **contexte → décision → conséquences**. On ne modifie
pas un ADR accepté ; on en écrit un nouveau qui le remplace.

| [0003](0003-choix-des-modeles.md) | Choix des premiers modèles réels (moteur « local ») | Accepté |
| [0004](0004-rag.md) | Base de connaissances et RAG | Accepté — domaine à valider |

Prochains ADR attendus : adaptation (fine-tuning) d'un modèle pour le Baoulé, réactivation de la
détection automatique de langue, résultats d'évaluation des modèles sur le jeu de test.

Modèle : copier un ADR existant et renseigner Statut, Date, Contexte, Décision, Conséquences.
